# Rockman X / Mega Man X Password Generator & Analyzer

ロックマンX（Mega Man X）のパスワードを任意の進行状況で生成し、逆にパスワードから状態を分析するツール。

## Features
- Generate password from preferred state (bosses, Heart Tanks, Sub-Tanks, Armor)
- Analyze password back to state
- UI language switch: Japanese (Japan version) / English (NA/EU versions)

## Usage
Open `index.html` in a browser (or host on GitHub Pages).
